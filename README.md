# Analytical and Numerical Methods for the Black–Scholes Equationin European Option Pricing

Project for **Partial Differential Equations with Applications in Physics and
Industry**.

The repository contains a Jupyter-based project about European option pricing
with the Black-Scholes equation. The code is organized in a reusable `src/`
package so the main notebook can import functions instead of keeping all logic
inside notebook cells.

## Project Scope

The project follows the plan from `notebooks/Plan.ipynb`:

1. derive and discuss the Black-Scholes PDE,
2. explain terminal and boundary conditions for European call and put options,
3. connect the Black-Scholes equation with the heat equation,
4. compute exact analytical Black-Scholes prices,
5. solve the PDE with a finite difference method,
6. compare numerical and analytical prices,
7. perform grid convergence and parameter sensitivity analysis,
8. optionally compare model prices with BTCUSDT option market prices.

## Setup

Create and activate a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e .
```

Open the main notebook:

```powershell
jupyter notebook notebooks/main.ipynb
```

The notebook adds `src/` to `sys.path`, so imports work as:

```python
from black_scholes_pde import BlackScholesParams, GridParams, solve_explicit_fd
```

## Current Modules

- `black_scholes.py` implements European call/put payoff functions and the exact
  Black-Scholes formula.
- `finite_difference.py` implements a stable finite difference solver for the
  Black-Scholes PDE.
- `analysis.py` contains error metrics and convergence table generation.
- `volatility.py` estimates annualized volatility from historical prices.
- `visualization.py` contains reusable Matplotlib plots.
- `market.py` stores manually collected option quotes for the BTCUSDT comparison.

## Notes

The finite difference method is validated against the exact Black-Scholes
formula. Market prices, such as BTCUSDT option quotes, are intended as a
practical comparison and may differ from the model because of implied
volatility, liquidity, bid-ask spread, jumps, and other market effects.
